# 1. 产品概述

## 1.1 产品定位

XOR NIM 是一款基于经典尼姆博弈（Nim Game）的策略益智游戏。

玩家通过控制能量阵列中的资源数量，与 AI 进行回合制博弈。

游戏核心机制：

- 玩家每回合选择一个能量阵列；
- 移除任意数量的能量核心；
- 通过二进制异或（XOR）计算判断局面优势；
- 最终通过策略制造必胜局面。

产品目标：

1. 提供具有游戏性的策略体验；
2. 通过视觉化方式帮助玩家理解二进制异或；
3. 将数学理论转化为直观可玩的游戏机制。

## 4.2.2 AI难度

### 简单模式

策略：

- 随机操作为主
- 部分采用最优策略

目标：

帮助新玩家熟悉规则。


### 普通模式

策略：

- 70%最优操作
- 30%随机操作

目标：

提供挑战但允许玩家获胜。


### 困难模式

策略：

完全采用尼姆必胜算法。

计算：

```
NimSum =
A1 XOR A2 XOR A3 ... XOR An
```

当：

```
NimSum ≠ 0
```

寻找：

```
target = pile XOR NimSum
```

满足：

```
target < pile
```

执行：

```
remove = pile - target
```

使：

```
NimSum = 0
```

# 5. 核心交互设计

# 5.1 阵列选择

## 操作

玩家点击某个能量阵列。

## 反馈

选中状态：

- 阵列上浮；
- 外圈发光；
- 其他阵列降低透明度；
- 手机轻微震动。


动画：

持续：

200ms～300ms

---

# 5.2 能量核心移除操作

## 推荐交互

采用滑动选择。

示例：

原状态：

```
◇ ◇ ◇ ◇ ◇ ◇ ◇
```

向左滑动：

```
◇ ◇ ◇ ◆ ◆ ◆ ◆
```

其中：

◇ 保留

◆ 待移除


实时显示：

```
7 → 3

准备移除4个核心
```

# 7. XOR核心设计

## 状态

### 不稳定状态

条件：

```
XOR != 0
```

显示：

- 橙红色；
- 能量波动；
- 核心震动。


### 稳定状态

条件：

```
XOR = 0
```

显示：

- 青绿色；
- 光环扩散；
- 稳定提示。
